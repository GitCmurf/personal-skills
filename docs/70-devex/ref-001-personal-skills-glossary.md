# REF: Personal skills glossary

<!-- MEMINIT_SECTION: content -->
<!-- AGENT: Fill this section with the document-specific content. -->

## Content

- **Upstream:** the public source from which a skill or skill system originated.
- **Upstream baseline:** the exact reviewed upstream commit recorded for a local
  adaptation.
- **Personal skill:** a skill whose behaviour and maintenance policy are governed
  by this repository, whether originally written here or adapted under licence.
- **Managed plugin:** an app-managed installation or cache. It is read-only from
  this repository's point of view and is not a safe home for personal edits.
- **Installation link:** a junction or symbolic link from the standard discovery
  location to a skill in the canonical checkout.
- **Upstream refresh:** a reviewed change that advances an upstream baseline and
  reconciles the local adaptation. It is never an unattended overwrite.
- **Candidate name:** a temporary, non-colliding skill name used to compare a
  proposed replacement. Candidate skills must not allow implicit invocation.
- **Project adapter:** narrow project guidance that adds local context without
  copying or contradicting PEPYS, Meminit or the personal skill.
- **Reader cost:** the effort imposed on the intended reader by avoidable jargon,
  abstraction, repetition or structure.
- **Protected material:** text whose exact form carries authority or meaning,
  including quotations, commands, identifiers, frontmatter, evidence and code.
